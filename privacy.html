隱私權政策 / Privacy Policy

claude-cli-m6 是個人自用工具，僅由擁有者本人使用。

  • 透過 Google API 取得的資料只在擁有者自己的電腦上處理，不會上傳到任何第三方伺服器、不會出售或分享給他人。
  • OAuth 授權憑證只儲存在擁有者本機。
  • 使用者可隨時於 Google 帳戶權限頁面 撤銷授權。

claude-cli-m6 is a personal tool used only by its owner. Data accessed via Google APIs is processed locally on the owner's computer, is never sold or shared with third parties, and authorization can be revoked at any time from the Google Account permissions page.

Google API 資料的使用遵守 Google API Services User Data Policy，包括 Limited Use 規定。
